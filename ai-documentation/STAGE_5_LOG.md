## 3. Architecture & Separation of Concerns

The architecture preserves complete modularity and unidirectional data flow:

```
[ Recursion Config State ]
          │
          ▼
[ Stage 2: generateRecursiveTree(config) ]  ───► BranchEvent[]
          │                                           │
          ├──────────────────────────┐                │
          ▼                          ▼                ▼
[ Stage 3: CanvasTreeRenderer ]      [ Stage 4 & 5: mapRecursionToMusic ]
(Draws cosmic tree & highlights)     (Pure headless mapper: scale, tempo, events)
          ▲                                           │
          │ onActiveBranchesChange                    ▼
          │ (real-time branch IDs)              Composition
          │                                           │
          └───────────────────────────── [ WebAudioSynthesizer ]
                                         (Play, Pause, Resume, Stop, Replay, Sync)
```

1. **Pure Audio Engine (`src/lib/audio/audioEngine.ts`):**  
   Contains all Web Audio API nodes (`OscillatorNode`, `GainNode`, `BiquadFilterNode`, `DelayNode`, `StereoPannerNode`, `DynamicsCompressorNode`). It has zero DOM or React dependencies. Emits typed callbacks `onActiveBranchesChange(Set<string>)` and `onStateChange(PlaybackState)`.
2. **Pure Music Mapper (`src/lib/audio/musicMapper.ts`):**  
   Contains harmonic scales (`pentatonic`, `dorian`, `lydian`, `ambient`), tempo pacing formulas ($scaleFactor = 60 / BPM$), register layering, and polyphony throttling ($\le 8$ simultaneous voices).
3. **Canvas Visualization (`src/lib/visualization/canvasRenderer.ts`):**  
   Accepts `setHighlightedBranches(branchIds: Set<string>)`. When sounding branches are received, it renders an electric starlight glow (`rgba(240, 249, 255, 0.99)`) with cyan corona (`rgba(56, 189, 248, 0.95)`) and expansion rings on terminal nodes while maintaining the tree stationary.
4. **Interactive Application Shell (`src/app/page.tsx`):**  
   Acts as the unified state conductor, coordinating UI events from `PlaybackPanel`, `ParameterPanel`, and `VisualizationPanel`.

- **Ambient Reverb Slider (0–100%):** Controls delay feedback return wet level for spatial reverberation.

### B. Precise Pause & Resume Offset Logic
Web Audio's `AudioContext.currentTime` runs monotonically and cannot be paused. We solved this with virtual timeline offset tracking:
1. When **Play** is invoked: `playbackStartTime = ctx.currentTime + 0.08`, `pausedAtSec = 0`.
2. When **Pause** is invoked:
   ```ts
   const elapsed = Math.max(0, this.ctx.currentTime - this.playbackStartTime);
   this.pausedAtSec = Math.min(elapsed, this.currentComposition.totalDuration);
   this.stopAudioNodesOnly();
   this.stopSyncLoop();
   this.updateState("paused");
   ```
3. When **Resume** is invoked:
   ```ts
   const now = ctx.currentTime + 0.06;
   this.playbackStartTime = now - this.pausedAtSec;
   for (const evt of this.currentComposition.events) {
     if (evt.startTime + evt.duration > this.pausedAtSec) {
       const delayOffset = Math.max(0, evt.startTime - this.pausedAtSec);
       this.synthesizeEvent(ctx, evt, now + delayOffset);
     }
   }
   ```
4. When **Stop** is invoked: `pausedAtSec = 0`, state is set to `"stopped"`, all scheduled events and active branch highlights are cleared.

### C. Audio-Visual Synchronization
- A high-precision `requestAnimationFrame` loop in `WebAudioSynthesizer` checks:
  $$curTime = audioCtx.currentTime - playbackStartTime$$
  $$ActiveBranchIds = \{ evt.branchId \mid curTime \ge evt.startTime \land curTime < evt.startTime + evt.duration \}$$
- Emitted to `onActiveBranchesChange(Set<string>)`.
- `CanvasTreeRenderer.setHighlightedBranches(branchIds)` immediately renders sounding branches in radiant starlight white with cyan aura without modifying tree camera bounds or branch coordinates.
